# Image Hosting for Tilda Project

Репозиторий предназначен для хранения и организации медиа-контента (изображений, иконок, графики), которые используются в проекте на Tilda. Использование GitHub в качестве хостинга позволяет получать прямые ссылки на файлы и обходить ограничения встроенной библиотеки Tilda.

## Как использовать изображения в Tilda

Чтобы вставить изображение из этого репозитория на страницу Tilda:

1. Загрузите изображение в папку проекта.
2. Получите **прямую ссылку (Direct Link)** на файл:
   - Откройте файл в интерфейсе GitHub.
   - Нажмите кнопку **"Raw"**.
   - Скопируйте URL из адресной строки браузера.
   - *Пример формата ссылки:* `https://raw.githubusercontent.com/username/repository/main/img/2015/your-image.jpg`
3. В Zero Block или стандартном блоке Tilda выберите **"Upload by URL"** и вставьте скопированную ссылку.
